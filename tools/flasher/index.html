Flash the boards

For the Seeed XIAO ESP32S3 + Wio-SX1262 kit. This replaces the Meshtastic firmware the kit ships with; you can put Meshtastic back any time from its flasher.

This browser can't reach a USB board. Use Chrome or Edge on a laptop or desktop.

1. Detector

  1. Screw the antenna on first. Transmitting without one can damage the radio.
  2. Plug the board in with a USB-C data cable, tap Install detector and pick the port (USB JTAG/serial).
  3. Tick Erase device the first time, to clear Meshtastic.

2. Gateway

Put in both phones' hotspots. The gateway joins whichever one is on, so on the day either phone can be the logger, and you can swap by turning one hotspot off and the other on. Each phone's hotspot name and password are on its hotspot settings screen.

Made up for you; change it only to match a logger you've already set up. The board only sees 2.4 GHz, so on an iPhone switch on Maximize Compatibility.

Fill in at least one hotspot name and the gateway ID first.

Then, on whichever phone will be the logger, turn on its hotspot, open the logger and tap Logger phone. Gateway shows up there by itself about 30 s after the board has power: tap it. To use this computer as the logger instead, for the meter step at home, open the logger here.

If it won't connect

Hold the B (boot) button on the XIAO, plug in the cable, then let go. Try again.

What gets written

Both boards get the same random network key, made once in this browser, so flash both from the same computer. The gateway also gets your hotspots, the public broker mqtt://broker.hivemq.com:1883 and the gateway ID. Nothing you type leaves this page.
