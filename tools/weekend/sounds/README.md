# Drone sounds for the speaker test

Played by the weekend logger's Speaker panel. Both come from [batear-datasets](https://github.com/batear-io/batear-datasets) (MIT, see `LICENSE-batear-datasets.txt`), cut, high-passed at 120 Hz to drop wind rumble, and normalised to about -1 dBFS peak.

| File | Source | Segment |
|---|---|---|
| `mini.mp3` | `field-tests/DJI/mini-4-pro/20260428/2474750763FAA288_20260428_080410.WAV`, DJI Mini 4 Pro, 4.7-13 m from the recorder | 28-42 s, steady 216 Hz rotor tone |
| `fpv.mp3` | `field-tests/FPV/5inch_resampled/20260415_192501.wav`, 5-inch FPV, distance not recorded | 1-8 s, tones near 740 and 1480 Hz |
